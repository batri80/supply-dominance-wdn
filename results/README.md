# Results of the reported runs

JSON result files and logs from the runs reported in the paper (macOS, Python 3.11,
WNTR 1.4.0, PyTorch 2.2.2, 15 worker processes). Rerunning `run_all.py` writes the same
files to `outputs/`. `README.md` at the top level maps each file to the table or figure it
supports. Large intermediate files (scenario arrays, leak libraries) are not stored; they
are regenerated by the corresponding stage.
